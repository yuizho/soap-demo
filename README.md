# SOAP Demo

## Getting Started
```sh
./mvnw clean spring-boot:run
```

- Java codes for Soap is generated by cxf-codegen-plugin and `src/main/resources/wsdl/inventory.wsdl` at generate-sources phase
- the SOAP service is exposed at http://localhost:8080/ws/inventory
- You can access to the service by some HTTP client tool like Postman
  - If you use post man, you can you can import `src/main/resources/wsdl/inventory.wsdl` to create a collection
